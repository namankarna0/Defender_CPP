# 🛡️ DEFENDER++

**DEFENDER++** is a cybersecurity-focused web project designed to provide a collection of security tools through a modern, interactive, and user-friendly interface.

The project combines **HTML, CSS, JavaScript, and C++** to demonstrate concepts related to password security, encryption/decryption, system monitoring, and network security.

## 🚀 Features

### 🔐 Password Tools

* Random Password Generator
* Custom password length
* Lowercase characters
* Uppercase characters
* Numbers
* Symbols
* Copy generated password
* Generate password again
* Password security information

### ⚔️ Password Attack Simulator

* Password input interface
* Theoretical password attack analysis
* Estimated attack time
* Password visibility toggle
* Security-focused UI for demonstrating password strength concepts

### 🔒 Encryption

* Encrypt Text interface
* Encrypt File interface
* Password-based encryption interface
* Encrypted output display
* Password show/hide button

### 🔓 Decryption

* Decrypt Text interface
* Decrypt File interface
* Encrypted message input
* Password input
* Decrypted output display
* Password show/hide button

### 🖥️ Monitor System

* System monitoring interface
* Designed for displaying system/security-related information

### 🌐 Port Scanner

* Port scanning interface
* Designed for security and network analysis
