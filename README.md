# 🛡️ DEFENDER++

DEFENDER++ is an educational cybersecurity toolkit built with **HTML, CSS, JavaScript, and C++**. It provides a modern interface for exploring password security, encryption/decryption, network scanning, and system monitoring.

## 🚀 Features

- 🔐 Random Password Generator
- ⚔️ Password Attack Simulator
- 🔒 Text & File Encryption
- 🔓 Text & File Decryption
- 🌐 Port Scanner
- 🖥️ System Monitor
- 🎨 Animated Cybersecurity-themed UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- C++
- CMake
- MinGW-w64
- Git & GitHub

## 📁 Structure

```text
Defender/
├── backend/
├── frontend/
├── CMakeLists.txt
├── start.sh
└── README.md

⚙️ Setup
Clone the repository:

git clone https://github.com/YOUR-USERNAME/DEFENDER.git
cd DEFENDER

Configure the C++ backend:
cmake -S . -B build -G "MinGW Makefiles"

Build:
cmake --build build

For the frontend, open:
frontend/index.html

using VS Code Live Server.
▶️ Run

Start the C++ backend using the generated executable, and open the frontend with Live Server.

If configured, you can also use:

./start.sh
⚠️ Disclaimer

DEFENDER++ is intended for educational purposes and authorized security testing only. Do not use its security tools against systems or networks without permission.
